# Ruby 品妍入口網站（可操作靜態版）

本成品以使用者指定的「Ruby 品妍 入口網站－完整網站架構圖」為主要資訊架構，提供可在手機／平板／電腦瀏覽的繁體中文網站。

## 啟用

1. 解壓縮 `ruby_portal_website.zip`。
2. 打開解壓縮資料夾內的 `index.html`，即可直接預覽網站。
3. 要正式公開，將整個資料夾（含 `assets`、`styles.css`、`app.js`）上傳至支援靜態網站的主機，例如 Netlify、GitHub Pages 或既有網頁空間。
4. 網址與素材連結為相對路徑，請不要只上傳 HTML 而漏掉 `assets`。
